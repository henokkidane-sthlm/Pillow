:py:mod:`~PIL.ImageTiles` module
================================

The :py:mod:`~PIL.ImageTiles` module provides helpers for clamping crop boxes,
splitting an image into square tiles, and counting the tiles needed to cover
an image with :py:func:`tile_count`.
